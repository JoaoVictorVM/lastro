Acesso e clínicas

Documentação sintética de acesso à aplicação demo do Lastro.

Login

O acesso é feito com email e senha. Depois do login, a pessoa é levada para a listagem de funcionários da sua clínica.

Clínicas

A demo atende várias clínicas no mesmo sistema, como a Clínica Aurora e a Clínica Boreal. Cada clínica enxerga apenas os próprios funcionários.

Usuário com mais de uma clínica

Uma pessoa vinculada a mais de uma clínica escolhe a clínica ativa depois do login. Todas as telas passam a mostrar somente os dados da clínica escolhida.

Sessão

Sair do sistema encerra a sessão. Para acessar novamente é preciso fazer login outra vez.
